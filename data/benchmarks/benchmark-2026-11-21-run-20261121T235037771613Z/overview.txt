WHAT THE NUMBERS MEAN

A tick is one server update. Processing time measures the work in a tick. Tick spacing is the time between the start of
one update and the start of the next. p99 is the time within which about 99 out of 100 measured ticks finished their
work.

A process CPU value of 100% means one fully occupied core. Resident memory is RAM held by the JVM process. The JVM heap
stores Java objects. Both may grow as workload changes. A memory leak requires evidence that the program keeps objects
it can no longer use.
